# Acarmor HVAC & Renewables Web Platform

A bespoke, high-end web application built for Acarmor, a premium HVAC and renewable energy company. Designed to deliver an "Airy & Elevated" user experience, the platform brilliantly highlights core services including Air Conditioning, Heat Pump Installation, Solar PV, and Heating Engineering. 

The aesthetic leverages a custom, intelligent CSS-based design system that relies on smooth micro-animations, glassmorphism, and a highly conversion-optimized flow.

## 🌟 Key Features

- **Premium Bespoke Design**: A meticulously hand-tailored CSS design system prioritizing vibrant performance over generic utility framework looks. 
- **Dynamic Navigation System**: Responsive, state-aware navigation that dynamically adapts color schemes when scrolling over dark heros and light sections for maximum readability.
- **Action-Oriented Architecture**: Conversion-optimized UI driving lead generation toward "Get a Free Estimate" CTAs.
- **Top-Tier Performance**: Lightning-fast compilation and runtime powered by React & Vite.

## 🛠️ Tech Stack

- **Framework**: React.js
- **Build Engine**: Vite
- **Styling**: Pure CSS (Custom Tokens & Utilities)

## 🚀 Getting Started

**1. Install dependencies:**
```bash
npm install
```

**2. Start the development server:**
```bash
npm run dev
```

**3. Build for production:**
```bash
npm run build
```
