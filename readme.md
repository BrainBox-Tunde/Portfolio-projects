# Portfolio Projects

This repository contains modern, high-end web applications and portfolio builds:

1. **[Plumber Next Door of Sandy Springs](./plumber-next-door/)**: A bespoke single-page web experience for a local plumbing company in Sandy Springs, GA. Features an interactive problem selector, comprehensive 50+ item service catalog, interactive service area ZIP checker, smart dispatch form with photo upload, documentary photography, and a pure CSS design system.
2. **[Acarmor HVAC & Renewables](./acarmor-web/)**: An airy, elevated platform for HVAC, Heat Pumps, and Solar PV services.
